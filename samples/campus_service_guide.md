# 校园智能服务知识库样例

## 系统定位

AI 知识库文档问答系统用于把校园制度、部门办事流程、项目文档和常见问题沉淀为可检索的知识库。
用户输入问题后，系统会先进行文本向量化，再从知识库 chunk 中检索最相关内容，最后生成带引用来源的回答。

## RAG 流程

完整流程包括文档上传、文本解析、文档切分、向量生成、索引入库、问题检索、答案生成和引用来源展示。
系统默认使用本地 Hashing Vector 方案，便于无 API Key 环境下运行。
后续可以升级为 OpenAI Embedding、sentence-transformers、FAISS 或 Chroma。

## 管理能力

后台管理页面支持新增文档、上传 TXT、Markdown、CSV、JSON、PDF 文件、删除文档、重新构建索引。
每份文档会被切分为多个 chunk，并保存 chunk 编号、文本内容、向量和 token 数量。

## 问答日志

系统会记录每次用户问题、生成答案、检索置信度、引用来源和用户反馈。
用户可以把答案标记为有用或无用，便于后续分析哪些问题命中不足、哪些文档需要补充。

## 适用场景

适用于企业内部知识库、校园办事问答、项目文档助手、客服 FAQ、规章制度查询和 Agent 工具前置检索模块。
